# Computer Networks - Laboratory Works

This branch contains three laboratory assignments completed as part of my university coursework in computer networks. The assignments cover IP addressing, subnetting, network topology design, network configuration, and routing protocols.

## Laboratory Assignments

### 1. IPv4 Addressing and Subnetting
Practical exercises focused on IPv4 addressing, subnet mask calculation, network and broadcast address identification, and dividing networks into subnets.

### 2. VLAN, DHCP, NAT, PAT, and OSPF
Network configuration exercises involving Virtual LANs (VLANs), DHCP server configuration, Network Address Translation (NAT), Port Address Translation (PAT), and the OSPF dynamic routing protocol.

### 3. Network Addressing, Topology, and Routing
Exercises covering basic network address calculations, network topology design, static routing configuration in AS1, and dynamic OSPF routing in AS3.

## Skills and Technologies

- IPv4 addressing and subnetting
- Network topology design
- VLAN configuration
- DHCP services
- NAT and PAT configuration
- Static routing
- OSPF dynamic routing
- Network configuration and troubleshooting

These laboratory assignments provide practical experience in network design, addressing, configuration, and routing. They demonstrate my understanding of fundamental networking concepts and their application in simulated network environments.

# Компьютерные сети - лабораторные работы

Данная ветка содержит три лабораторные работы, выполненные в рамках университетской программы по компьютерным сетям. Работы охватывают IP-адресацию, разделение сетей на подсети, построение сетевых топологий, настройку сетевого оборудования и протоколы маршрутизации.

## Лабораторные работы

### 1. IPv4-адресация и разделение сетей на подсети
Практические задания по IPv4-адресации, расчёту масок подсетей, определению сетевых и широковещательных адресов, а также разделению сетей на подсети.

### 2. VLAN, DHCP, NAT, PAT и OSPF
Настройка виртуальных локальных сетей (VLAN), DHCP-серверов, трансляции сетевых адресов (NAT), трансляции портов (PAT) и динамической маршрутизации с использованием OSPF.

### 3. Сетевая адресация, топология и маршрутизация
Расчёт базовых сетевых адресов, построение топологии сети, настройка статической маршрутизации в AS1 и динамической маршрутизации OSPF в AS3.

## Полученные навыки и используемые технологии

- IPv4-адресация и разделение сетей на подсети
- Проектирование сетевых топологий
- Настройка VLAN
- Работа с DHCP-сервисами
- Настройка NAT и PAT
- Статическая маршрутизация
- Динамическая маршрутизация OSPF
- Настройка и диагностика компьютерных сетей

Выполнение лабораторных работ позволило получить практический опыт проектирования, адресации, настройки и маршрутизации компьютерных сетей. Работы демонстрируют понимание основных сетевых технологий и их применение в моделируемых сетевых средах.
